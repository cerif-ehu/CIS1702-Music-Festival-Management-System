# Comment Formatting
This section contains how comments should be made when programming for this task. Please stick to this agreed upon format:

**Single-line Comments:**
```python
# Enter Comment Here (Name Of Who Added Comment)
```

**Multi-line Comments:**
```python
"""
Enter Comment Line 1
Enter Comment Line 2
...
(Name Of Who Added Comment)
"""
```

**To-do Comments:**
```python
# TODO: Enter Task To-do (Name Of Who Added Comment)
```
